# P70 主线规格（M）—— 乖离率均值回归腿

**写作时点：2026-08-06，S 校准位返回之前。** 本文件存在的唯一目的是与 S 位独立写出的
规格逐字段 diff；git 提交顺序可查（本文件 commit 早于 S 位产物落库）。**写完不再修改**，
diff 出的差异另开一节记录，不回来改这份。

## 待形式化的原话

> 「我不是说乖离率异常后买入就不动了，卖出就不动了，而是说这个指标本身就是可以赚数学
> 意义上均值回归的过程。基于这个出发点，你先准备好需要的数据，然后用多个 Agent 交叉验证
> 数据质量，然后再设计一个操作策略。最后再用多个 Agent 交叉验证这个策略效果。另外你再
> 看一下，这些极值点位和恐慌情绪极值是否有一定相关性。」

## 1. 被交易的对象

**价格。** 账户只能买卖指数 ETF，**不能直接交易 bias**。所以「赚 bias 均值回归的钱」的
可执行含义只能是：**在 bias 处于极值时建立价格头寸，在 bias 回归到中枢时了结，赚取期间的
价格变动。**

🔴 **这条推论是整个规格的要害**：bias 回归 ≠ 价格上涨。由恒等式
`Δln(1+b) = ln(P涨幅) − ln(MA涨幅)`，bias 回归可以完全由均线自己走过来实现。
⟹ **规格必须把「价格腿占比」列为一等评价指标**，不能只看 bias 有没有回归。

⚠️ 原话未指定，我的补全：owner 说的是「赚均值回归的过程」，我读作「赚价格的钱」。
另一种读法是「用 bias 回归作为择时依据、赚的是别的东西」——但账户只有价格一个盈亏来源，
两种读法在可执行层面收敛到同一条。

## 2. 入场

- 指标：`bias60 = 收盘 / MA60 − 1`（价格指数、不复权）。MA20/MA120 作并列对照臂。
- 极值定义：**因果口径**（截至当日可知），主口径用 expanding 分位 ≤ X%；
  X ∈ {2%, 5%, 10%} 三档并列。排名口径（前 K 名）作对照臂。
- **双尾**：低尾 → 买入；高尾 → 减仓/清仓。

⚠️ 原话未指定「异常」的阈值，我的补全是分位而非排名。理由：E57/E58/E59 已实证排名口径
十年不响一次（触发数 ≈ 4/win×N），而 owner 这次的命题是「这个指标本身」的统计性质，
应该用能反复触发的口径去测，否则测的还是"稀有事件"不是"均值回归"。

## 3. 出场 —— 🔴 与 E59 的关键差别就在这一条

**bias 回归到中枢即平仓**，不等反向极值。中枢定义三档并列：`bias ≥ 0`（完全回归）/
`bias ≥ −X/2`（回归一半）/ `bias` 回到 50 分位。**另加最大持有期兜底**
（H_max ∈ {60, 120} 交易日），防止长熊里无限持有。

⚠️ E59 的出场是「等一个反向极值信号」＝方向性赌注，owner 明确说那理解错了。
本规格的出场绑定在**指标回归**上，这才是「赚均值回归的过程」。

## 4. 仓位

单腿满仓 / 空仓两态（主口径），与 E57/E58/E59 可比。分档建仓（越极端越重）作对照臂。
各指数各自独立记账、互不挪用资金。

⚠️ 原话「不要每次 10%」是对 E58 那个 sleeve 说的，我读作「就按这条腿本身满仓算，
不做组合稀释」。

## 5. 做空腿

**不做空。** A 股宽基做空需融券或股指期货，成本与门槛都不适合本账户，且系统零自动交易。
高尾那一头只作**减仓已持有的头寸**，即：高尾时若持有则清仓，若空仓则不动。

⚠️ 原话「高的低的都要算」出自上一轮（E59），本轮未重申。我延续双尾但把高尾降级为
「只减不空」。

## 6. 计价与执行

信号日 T 产生，**T+1 收盘成交**（exec_lag=1）。往返成本 0.06%。空仓期现金按 2%/年计息。
基准：同标的买入持有（同起点同终点）。

## 7. 评价指标（缺一不可）

1. 年化 / 夏普 / 最大回撤 vs 买入持有；
2. **价格腿占比**——回归量里价格实现了多少（第 1 节的要害）；
3. 触发频次与近十年触发次数（E58 判据⑤的固定条款，所有中短线提案必带）；
4. 分期稳健性（标定五已证价格腿符号分期翻转，这一条必须进判据不能作附注）；
5. 三条从未参与调参的对照指数（上证50/中证500/中证1000）单列。

## 8. 恐慌相关性那一问

精确统计问题：①水平秩相关（并且**必须先剔除恐慌分里价格派生的分量①②**，否则 2/5 是
定义带来的）；②极值集合的条件概率与 Jaccard；③领先滞后（对日度**变化**求相关）；
④ episode 层面的时间距离。**结论只作描述，不进买卖闸**——除非另立判据。

## 9. 我认为这个想法最可能在哪里失败

1. **均线腿吃掉全部回归**（标定二已见：大盘腿全样本低尾价格腿为负）；
2. **触发日高度集中在 2008/2015**，样本的有效独立事件数远小于触发日数；
3. **「回到中枢即平仓」在长熊里会反复被止损**，因为中枢自己在往下走。
