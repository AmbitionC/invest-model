## 1. 被交易的对象到底是什么（本规格的核心）

### 1.1 恒等式（这是全部推理的地基）

设 `MA_t` = 最近 N 个交易日收盘价简单平均（N=60），`bias_t = P_t / MA_t − 1`。

对任意持有区间 `[t, t+h]`：

```
P_{t+h} / P_t  =  (MA_{t+h} / MA_t)  ×  (1 + bias_{t+h}) / (1 + bias_t)
```

取对数，得到**精确、无残差**的两项分解：

```
r_total  =  r_anchor  +  r_conv
r_anchor =  log( MA_{t+h} / MA_t )          ← 锚漂移项（60日均线自己走了多远）
r_conv   =  log( (1+bias_{t+h}) / (1+bias_t) )  ← 收敛项（乖离率本身回归贡献了多少）
```

### 1.2 我的判读

**被下注的量是 `r_conv`；被买卖的工具是价格（指数 ETF）；账户实际拿到的是 `r_total`。**

「赚 bias 均值回归的钱」的精确含义 = **在 `r_conv` 上取正期望**。
但因为不存在可交易的 bias 工具，`r_conv` 只能**捆绑着 `r_anchor` 一起被买下**。
因此整个策略的可行性等价于一个不等式：

```
E[r_conv]  >  −E[r_anchor]  +  交易成本 + 持有期管理费 − 空仓期利息
```

**规格的强制要求**：每一笔交易必须同时输出 `r_total / r_anchor / r_conv` 三个数，
并逐笔断言 `|r_total − r_anchor − r_conv| < 1e-12`。任何只报总收益的实现视为不合规。

**判读依据**：
1. 原话说「这个指标**本身**就是可以赚数学意义上均值回归的过程」——「指标本身」把标的从价格
   明确地移到了 bias 这个量上；而「数学意义上」提示他要的是 `bias → 中枢` 这个**机械收敛**，
   不是「跌多了会涨回来」这个市场判断。这两件事在数学上是不同的：bias 一定回归（因为 MA 是
   价格自己的滞后平均，它被定义为**必然**追上价格），而价格不一定涨回来。
2. 「不是买入后就不动、卖出后就不动」——排除了状态机式的长持，指向一个有**明确目标位**的、
   可重复很多次的交易，这只有把目标定义在 bias 这个量上才讲得通。

### 1.3 我认为的其他合理读法（必须并列记录）

- **读法 B（字面但基本不可执行）**：真的去交易 bias 本身。唯一实现是**横截面配对**：
  同时做多 bias 最低的指数、做空 bias 最高的指数，两腿的 `r_anchor` 部分对冲，剩下的近似纯 `r_conv`。
  这是唯一能把 `r_anchor` 真正剥离的做法。可行性见 §5：只有沪深300/上证50/中证500/中证1000
  有股指期货，创业板指、科创50、中证红利没有 ⇒ 7 腿里只有 4 腿能配对，且配对腿必须同向同规模。
  **规格要求把读法 B 作为对照臂 X1 实现（仅 IF/IH/IC/IM 四腿），不作为主口径。**
- **读法 C（最朴素，实现上与 A 等价）**：把 MA 当作浮动目标价——「跌到离均线太远就买，回到均线附近就卖」。
  数学上 target price = `MA_{t+h} × (1 + b_target)`，与读法 A 的出场条件同构。
  C 与 A 的差别不在实现，在**归因**：C 不要求分解，A 要求分解。因为归因决定了我们能不能
  判断「这个想法为什么成/为什么败」，规格取 A。
- **读法 D（把 bias 当波动刻度）**：不入场出场，只用 bias 调制一个常设底仓的权重。
  这实际上是 §5 的 H1 腿。若 A 与 B 都失败，D 是唯一的退路。

### 2.2 派生量定义（逐字段写死）

```python
MA60_t   = close.rolling(60, min_periods=60).mean()     # 严格 60，禁止 min_periods<60
bias_t   = close_t / MA60_t - 1                          # 前 59 个交易日必须为 NaN
mu_t     = bias.expanding(min_periods=WARM).mean()       # 只用截至 t 的信息（含 t）
sd_t     = bias.expanding(min_periods=WARM).std(ddof=1)
z_t      = (bias_t - mu_t) / sd_t
```

- `WARM = 750` 个交易日（约 3 年）。⚠️ **原话未指定，我的补全是 750**。
  理由：标准差要稳定至少需要跨越一轮完整波动周期；750 是「够长但不至于把科创50 整段吃掉」的折中。
  另一种合理读法：`WARM = 250`（样本多但早期 z 极不稳）或 `WARM = 1250`（更稳但科创50 只剩 2 年可用）。
  **规格强制：`WARM ∈ {250, 750, 1250}` 三档全跑并列报，任何结论若在三档间变号，一律判为不成立。**
- `expanding` 而非 `rolling`：⚠️ 补全。理由：rolling 窗口会让「极值」的定义随最近几年的波动幅度漂移，
  同一个 `bias = −10%` 在平静期算极值、在动荡期不算——那度量的是「最近有多吵」，不是「有多偏离」。
  另一种合理读法：`rolling(1250)`，好处是适应结构变化。**规格要求 expanding 为主口径，rolling(1250) 为对照臂 X2。**
- 一切统计量只用 `t` 及以前的数据。禁止全样本 `mean()/std()`。

## 3. 入场条件（S2）

```
低尾（买入腿） :  z_t <= -Z_in
高尾（减仓腿） :  z_t >= +Z_in
```

- `Z_in` 主口径 **2.0**；敏感性 `{1.5, 2.0, 2.5, 3.0}` 全跑。
  ⚠️ **原话未指定「异常/极值」的口径，我的补全是 z 分数阈值**。
  理由：(i) 七个指数的 bias 波动幅度差一倍以上，用同一个绝对阈值（如 −15%）会让创业板天天触发、
  上证50 十年不响，跨腿汇总统计就没意义了；(ii) 分位数口径在稀疏尾部极不稳定（第 1% 分位由
  个位数样本决定）；(iii) 排名口径（「历史前 N 低」）会随时间被永久锁死——2008 那种极端值一旦
  写进历史，后面十几年都够不着，信号会自然消亡。z 分数是三者里唯一既跨腿可比、又不会自我锁死的。
  **另一种合理读法**：分位口径（`bias` 在 expanding 分布中 ≤5% / ≥95% 分位）。
  **规格要求分位口径作为对照臂 X3 实现**，并报「两种口径的触发日重合率」——若 <70%，说明
  「什么叫极值」这个实现选择本身就在决定结论，须并列呈现两套结果。
- **双尾**。低尾与高尾是两条独立的腿，各自记账、各自评价，**不得合并成一条净值曲线后再下结论**。
- **冷却**：同一腿持仓期间不重复触发（不加仓，除非用 §4 的分档臂）；平仓当日起即可再次触发，
  **不设冷却期**。⚠️ 补全。理由：「均值回归」若成立就应该可重复收割，人为冷却会掩盖它是否可重复；
  另一种合理读法：20 日冷却以避免同一场危机被切成多笔而虚增样本量。
  **规格要求：主口径无冷却，但**统计显著性一律按 §7.4 的 episode 聚合**，这在效果上等价于冷却，
  且不损失交易层面的真实笔数。**
- **无前视**：`z_t` 只用 `≤ t` 的数据；`mu/sd` 用 expanding。

## 4. 出场条件（S3）—— 与前一轮的差别在这里

三个条件，**先到先执行**：

| 代号 | 条件 | 参数 |
|---|---|---|
| **E-CONV** | 低尾腿：`z_t >= Z_out`；高尾腿：`z_t <= -Z_out` | `Z_out = 0.0` 主口径；敏感性 `{-0.5, 0.0, +0.5}` |
| **E-TIME** | 持有满 `H_max` 个交易日无条件平仓 | `H_max = 60` 主口径；敏感性 `{20, 40, 60, 120}` |
| **E-STOP** | 相对入场收盘价回撤 ≥ `X_stop` | `X_stop = 12%` 主口径；**必须并跑 `X_stop = ∞`（无止损）臂** |

### 4.1 与前一轮的差别（逐条）

| 维度 | 前一轮（被 owner 否掉的） | 本规格 |
|---|---|---|
| 出场触发量 | **对面尾部的方向信号**（等 bias 走到另一头） | **同一条 bias 回到自身中枢**（`z→0`） |
| 出场语义 | 反转（reversal）：等市场走完一整个来回 | 收敛（convergence）：等偏离被抹平就走 |
| 典型持有期 | 数年（受制于「下一次极值什么时候来」） | 数周到数月（受制于 60 日均线的时间常数） |
| 一生笔数 | 个位数，且高度依赖两场危机 | 每腿每十年应有数十笔（若没有，见 §9 失败点 3） |
| 无信号时 | 一直持有 | 空仓（计息） |
| 被下注的量 | 价格方向 | `r_conv`（偏离的消失） |

**规格明令禁止**把「对面尾部信号」作为出场条件。若需量化差异，把它实现为**对照臂 A0**
（= 前一轮口径），与主口径并列报告——A0 存在的唯一目的是量化「换出场条件」值多少 pp，
不是候选方案。

### 4.2 `H_max = 60` 的理由（这个数不是随手挑的）

bias 的定义窗口就是 60 个交易日。一个 60 日均线上的偏离，若 60 个交易日内还没收敛，
说明它已经被**均线自己追上来**而抹平了——也就是 `r_conv` 是靠 `r_anchor` 反向变动实现的，
那不是我们想赚的钱。继续持有等于裸做多趋势，超出本规格的命题范围。
⚠️ 这仍是补全；另一种合理读法是 `H_max = 2N = 120`（给均线和价格各自一半时间）。

## 5. 持仓与仓位（S4）

- **每个指数是一个独立 sleeve**，初始资金 `1/K`（K = 参与腿数）。**不允许跨腿借用额度**——
  否则「买了 A 就买不起 B」会把信号质量和资金调度混在一起，归因就不干净了。
  ⚠️ 补全。另一种合理读法：单一资金池、先到先得（更接近实盘）。**规格要求单一资金池为对照臂 X4**，
  并报「因资金不足而漏做的信号笔数」。
- **单腿建仓**：主口径 **单档全额**（触发即把该 sleeve 的钱全投）。
  分档臂 X5：`z ≤ −2.0` 投 1/3、`z ≤ −2.5` 再投 1/3、`z ≤ −3.0` 再投 1/3（同一次 episode 内档位不重复触发）。
  ⚠️ 补全。理由：单档样本干净、便于做统计检验；分档更像人的实际做法但会让「每笔」的定义变模糊。
- **允许同时持有多个指数**。须报：同时持仓腿数的分布、各腿持仓期的两两重合率、
  以及「所有腿同时在场」的天数占比——若这个占比很高，说明七腿不是七个独立样本，
  §7.4 的有效独立事件数要相应打折。
- 单笔最大占用 = 该 sleeve 的 100%，即**账户口径**单笔最大 `1/K`。不加杠杆。

## 6. 高尾腿 / 做空腿（S5）

三种处理，**全部实现、分开报告**，不许只报一种：

### H0 — 不参与（基线）
只做低尾。高尾出现时什么都不做。这是「A 股宽基做空不便」的诚实默认。

### H1 — 底仓调制（我认为唯一无摩擦可执行的做法）
假设账户有常设底仓 `B = 25%`（⚠️ 补全，理由：这是个中庸的常设仓位数字；须做 `B ∈ {0, 25, 50}%` 敏感性）。
`z ≥ +Z_in` 时把该腿底仓降至 `B − Δ`（`Δ = 10pp`），`z ≤ 0` 时恢复至 `B`。
**评价基准必须是「一直持有 B」，不是绝对收益。** 即报 `Δ年化 = H1 − 恒定B`、`Δ回撤`、`Δ夏普`。
- **这条腿是「卖出已有持仓」，不是做空。** 它的上限就是 `B`，因此它不可能贡献很大的收益，
  真正的价值在回撤端。若 `Δ回撤` 不改善，H1 无意义。

### H2 — 真做空（仅在有工具的腿上）
| 腿 | 场内做空工具 | 可行性 |
|---|---|---|
| 沪深300 | 股指期货 IF | ✅ |
| 上证50 | IH | ✅ |
| 中证500 | IC | ✅ |
| 中证1000 | IM | ✅（上市较晚，须按合约上市日截断） |
| 创业板指 | 无 | ❌ 不可行 |
| 科创50 | 无 | ❌ 不可行 |
| 中证红利 | 无 | ❌ 不可行 |
- ETF 融券：券源不稳定、费率不确定、极端行情下最需要时最借不到 ⇒ **本规格判为不可行，不实现**。
- H2 须计入**基差/展期成本**：⚠️ 补全为**年化 3%**（对空头是收益还是成本取决于贴水方向，
  A 股股指期货长期贴水对空头**不利**，故按 3%/年 计为成本）。敏感性 `{0%, 3%, 6%}`。
  基差是时变的且我们没有基差数据，这是 H2 结果的**主要不确定性来源**，须在结论里显式标注。
- H2 只在四腿上有意义 ⇒ 它的样本量天然只有低尾腿的一半多一点，显著性检验须按四腿单独做。

**裁决口径**：若 H1 相对恒定底仓不加分（`Δ年化 ≤ 0` 或 `Δ回撤` 恶化 > 2pp），
则高尾腿不上线，整个策略退化为**只做低尾**。这个退化是允许的、且是我认为的大概率结果。

## 7. 计价与执行（S6）

### 7.1 时序
- 信号在 `t` 日**收盘后**计算（用 `close_t`）。
- 成交在 `t+1` 日**收盘价**。⚠️ 补全。理由：收盘价是我们唯一有的价格字段（CSV 只有 `close`），
  用开盘价成交需要我们没有的数据；且收盘成交无争议可复现。
  另一种合理读法：`t+1` 开盘成交（更接近「看到信号第二天早上买」），但须先补开盘价数据。
- **禁止 `t` 日收盘成交**（前视）。规格要求实现一个前视自检：把成交日改为 `t`，
  报 `Δ年化`；若 `Δ` 很大，说明策略高度依赖信号当日的那根 K 线，须在结论中标注脆弱性。

### 7.2 成本
- 交易成本：单边 **5bp**（ETF 佣金 + 冲击），双边 10bp。敏感性 `{0, 5, 15} bp`。
- 持有成本：ETF 管理费 + 托管费合计 **0.5%/年**，按**持仓自然日**计提。
  ⚠️ 注意这条对本策略是**有利**的：策略只在持仓时付费，买入持有全程付费。
  规格要求把「含费 vs 不含费」的对比同时报给策略和基准，避免这一项被误读成 alpha。
- 印花税：ETF 免，不计。

### 7.3 空仓资金
按年化 **1.5%** 单利、按自然日计息（货币基金口径）。⚠️ 补全。
理由：不计息会把「大部分时间空仓」的机会成本藏起来，让择时策略系统性虚高。
敏感性 `{0%, 1.5%, 2.5%}`。

### 7.4 统计口径
- **episode 定义**：同一腿内，一次「入场→出场」为一笔（trade）；
  **相邻两笔之间间隔 < 20 个交易日的，合并为一个 episode**。所有显著性检验按 episode 做，
  报 **有效独立 episode 数**。若某腿 episode 数 < 5，该腿**不得单独下结论**，只能进合并样本。
- **bootstrap**：block bootstrap，块长 = 中位持有期（交易日），2000 次重抽，报 95% CI。
- **置换检验**：保持每年触发次数与持有期长度分布不变，把入场日在**同一自然年内**随机重抽，
  1000 次，报策略的 `r_conv` 均值与 `r_total` 均值在随机分布中的分位 ⇒ p 值。
- **样本外**：`2005-01-01 ~ 2015-12-31` 为标定期，`2016-01-01 ~ 至今` 为保留期，**两段分开报**。
  上证50 / 中证500 / 中证1000 三腿**全程不得参与任何参数选择**，只在最终一次性评估。
- **稳健性前置门**（⚠️ 这条是我认为最容易被跳过的）：任何稳健性判据在评估前，
  必须先通过「**处理臂触发数 > 0**」的前置检查。零触发时一切稳健性判据平凡成立，
  必须报为「无效」而非「通过」。

## 8. 评价指标（S7）—— 「赚到了均值回归」该看什么

### 8.1 逐笔必报字段

| 字段 | 定义 |
|---|---|
| `r_total` | `log(P_exit / P_entry)` |
| `r_anchor` | `log(MA_exit / MA_entry)` |
| `r_conv` | `log((1+b_exit) / (1+b_entry))` |
| `resid` | `r_total − r_anchor − r_conv`，**断言 < 1e-12** |
| `hold_td` | 持有交易日数 |
| `exit_reason` | `CONV` / `TIME` / `STOP` 三选一 |
| `b_entry`, `b_exit`, `z_entry`, `z_exit` | |
| `fear_entry`, `fear_exit` | 若在恐慌数据区间内，否则 NaN |

### 8.2 主判定量

1. **`E[r_conv]` 及其 t 统计量 / 置换 p 值** —— 这是「乖离率是否真的均值回归」的直接度量。
   我预期这一条会**通过**（因为 MA 的定义保证了 bias 迟早回归）。
2. **`E[r_total]` 及其 t 统计量 / 置换 p 值** —— 这是账户真正拿到的钱。
   **这才是裁决量。** 1 通过而 2 不通过，是本想法最可能的结局。

### 8.3 收敛质量分解（回应「价格涨上去 vs 均线跌下来」这一问）

**这两者对账户完全不同，规格必须分开。** 定义：

```
Q = r_anchor / |r_conv|        （仅在 r_conv > 0 即收敛发生的笔上定义）
```

分四类计数并报占比：

| 类别 | 条件 | 语义 | 对账户 |
|---|---|---|---|
| **A 类：价涨回归** | `r_conv > 0` 且 `r_anchor ≥ 0` | 价格涨回来，均线也在涨 | ✅ 最好 |
| **B 类：纯回归** | `r_conv > 0` 且 `−0.5 < Q < 0` | 价格涨回来，均线小幅下滑 | ✅ 这是「理想的均值回归」 |
| **C 类：均线追上** | `r_conv > 0` 且 `Q ≤ −1` 且 `r_total < 0` | **bias 回归了，但靠均线自己跌下来抹平；账户亏钱** | ❌ 致命 |
| **D 类：未回归** | `r_conv ≤ 0` | 偏离扩大或不变 | ❌ 信号失效 |

**规格指定的头号数字**：

> **「bias 收敛成功（`r_conv > 0`）但该笔 `r_total < 0`」的笔数占比**

我认为这是本次研究**最重要的一个数字**。它直接检验 owner 的前提在「只能买卖价格」的约束下是否成立：
- 若该占比 < 20%：前提成立，bias 收敛主要靠价格实现，这个想法有基础。
- 若该占比 > 40%：**前提在工程上不成立**——信号可以 100% 有效（bias 确实每次都回归），
  而账户仍然不赚钱。此时无论怎么调阈值、调持有期都救不回来，因为问题在被交易对象的映射上，
  不在信号质量上。

### 8.4 其余必报指标
笔数 / episode 数 / 胜率 / 盈亏比 / 中位与均值持有天数 / `exit_reason` 三者构成比 /
年化贡献（按 sleeve 权重折算到账户）/ 均仓（持仓天数加权）/ 夏普。

**回撤须报两个数**，且必须并列：
- `DD_account`：账户净值口径最大回撤；
- `DD_inposition`：只在持仓期间计算的回撤。
⚠️ **明令**：若策略均仓很低，`DD_account` 小**不是风控效果，是没参与**。
报告中出现「回撤从 X 压到 Y」的表述时，必须同时给出均仓；均仓 < 50% 时该表述一律删除。

### 8.5 基准（三个，缺一不可）
- **B1 买入持有**该指数（同区间、同费率口径）。
- **B2 同均仓恒定混合**：每日仓位固定为策略的历史平均仓位 `w̄`，其余现金按 1.5% 计息。
  **这是剥离「低仓位躲跌」后的择时项基准**，是三个里最有信息量的一个。
- **B3 随机入场对照**：见 §7.4 置换检验。

## 9. 恐慌相关性（S8）—— 要回答的精确统计问题

样本区间硬性限定 **2015-01-05 起**（恐慌数据首日）。所有问题分指数报 + 合并报。

### Q1 同期相关（最弱的问题，但先看）
`Pearson ρ(z_bias_t, fear_t)` 与 `Spearman ρ`。分指数、分年份滚动（252 日滚动相关）画出来。
**预期方向**：`z_bias` 低（深度负偏离）应对应 `fear` 高 ⇒ 相关系数应为**负**。
若不为负，说明两者根本不是在测同一件事，后面几问的解释都要改。

### Q2 极值集合重合率（owner 问的「相关性」最字面的形式）
定义：
```
L = { t : z_t <= -2 }            低尾极值日
H = { t : z_t >= +2 }            高尾极值日
F = { t : fear_t >= θ_F }        恐慌极值日，θ_F 主口径 75
G = { t : fear_t <= 100-θ_F }    贪婪极值日，主口径 25
```
必报（对 `L∩F` 与 `H∩G` 各一套）：

| 量 | 说明 |
|---|---|
| `P(F｜L) = |L∩F| / |L|` | 给定 bias 极值，恐慌也极值的条件概率 |
| `P(L｜F) = |L∩F| / |F|` | 反向条件概率（两者通常差很多，必须都报） |
| Jaccard `|L∩F| / |L∪F|` | 对称度量 |
| **独立零假设下的期望重合数** `|L|·|F| / N` | **⚠️ 不报这个，重合率本身没有任何信息量** |
| Fisher 精确检验 p 值 | 2×2 列联表 |
| lift = 实际重合 / 期望重合 | |

- ⚠️ **θ_F = 75/25 是补全**（0~100 指标的常规极值刻度）。
  **强制网格** `θ_F ∈ {70, 75, 80, 85}`，并报「lift 是否随 θ_F 单调」——不单调说明是噪声。
- **判定口径**：`P(F｜L) < 20%` ⇒ 两者是不同时间尺度的量，**不能做 AND 门**（AND 后接近空集），
  最多做 OR 或分组；`P(F｜L) > 60%` ⇒ 恐慌可能只是 bias 的另一种测法，**须查是否冗余**（见 Q5）。
- 由于极值日高度成簇，**必须同时报 episode 级重合率**（把连续/邻近 20 交易日内的极值日合并为一个
  episode，再算重合），日级重合率会被自相关严重高估。**日级与 episode 级同时报，结论以 episode 级为准。**

### Q3 领先滞后（必须事前固定，不许事后挑 lag）
- 互相关函数 `CCF(z_bias, fear; lag)`，`lag ∈ [−20, +20]` 交易日，**41 个 lag 一次性全画出**。
  报最大 |ρ| 出现在哪个 lag，以及 **Bonferroni 校正（×41）后**是否仍显著。
  ⚠️ **规格明令：不得先看图再宣称「恐慌领先 k 日」。** 阶数若要用于任何后续规则，
  必须在跑数前指定，或用样本外确认。
- 事件级双向版本：
  - 以 `fear` **首次上穿 75** 为事件日 0，报 `z_bias` 在 `[−20, +20]` 的中位路径与四分位带；
  - 以 `z_bias` **首次下穿 −2** 为事件日 0，报 `fear` 的中位路径与四分位带。
  两条路径一起看，才能说清「谁先动」。

### Q4 增量价值（唯一能变成决策的问题）
在 §3 定义的低尾入场日上，按当日 `fear` 分两组（`fear ≥` 样本中位 vs `<` 中位），比较：
- `E[r_conv]` 差、`E[r_total]` 差、胜率差、`C 类占比` 差；
- Mann-Whitney U 检验 p 值 + block bootstrap CI。

**判据**：若两组差异不显著（p > 0.10）⇒ **恐慌对本策略无增量信息，不接线**。
若显著，须报方向：恐慌越高收敛越强（⇒ 可作加强条件），还是越弱（⇒ 恐慌是「还在跌」的标志，
应作**延迟**条件而非加强条件）。**这两个方向的操作含义完全相反，不许含糊带过。**

### Q5 冗余性 / 时间尺度（判断「恐慌是不是 bias 的马甲」）
- 对 `z_bias` 与 `fear` 各拟合 AR(1)，报一阶自相关系数与**半衰期**（`ln0.5 / ln φ`，交易日）。
- 若两者半衰期在同一量级（比值 0.5~2）且 Q1 的 |ρ| > 0.6 ⇒ 两者高度冗余，
  同时使用不构成独立证据，须在任何联合规则里明确指出。
- 若半衰期差一个量级 ⇒ 它们是不同频率的量，**这恰恰解释了为什么 Q2 的重合率会低**，
  并且意味着「用恐慌确认 bias」在定义上就不可能有高共现。

## 11. 我认为这个想法最可能在哪里失败（3 条）

### 失败点 1（我认为最可能）：信号会成功，账户不会赚钱——`r_conv` 与 `r_anchor` 的结构性反向
`MA60` 是价格自己的 60 日滞后平均，**它被定义为必然追上价格**。所以当价格深跌造成 `bias = −20%` 时，
接下来 60 个交易日里 bias 一定会向 0 收敛——但收敛可以完全由**均线自己滑下来**完成，
价格一步不涨甚至继续阴跌。此时 `r_conv > 0`（信号「兑现」了）而 `r_total < 0`（账户亏钱）。
这就是 §8.3 的 C 类。**「数学意义上的均值回归」是真的，但那个数学恒等式并不站在账户这边。**
判别方法已写死在 §8.3：看 C 类占比。若 > 40%，这个想法在只能买卖价格的约束下**不可修复**——
调阈值、调持有期都没用，因为问题在 §1.1 的分解上，不在信号上。
（唯一的修复方向是 §1.3 读法 B 的横截面配对，把 `r_anchor` 对冲掉；但那只有 4 条腿有工具、且吃基差。）

### 失败点 2：样本不独立到无法做任何统计
`z ≤ −2` 的日子会高度成簇，且几乎全部落在少数几场系统性下跌里。名义上可能有几百个触发日，
折成 episode 后可能只剩个位数，而且**七条腿在同一场危机里同时触发**，横截面相关性接近 1
⇒ 有效独立事件数可能只有 2~4 个。任何 p 值都会被自相关和横截面相关吹大。
这不是「样本还不够、再等等」的问题——十九年的数据已经用完了，它就是这个信号的信息量上限。
§7.4 的 episode 聚合 + block bootstrap + 置换检验是为这条准备的，但它们只能**如实揭示**这个问题，
不能解决它。

### 失败点 3：没有既有样本又有幅度的中间档，逼出参数漂移
放宽 `Z_in`（如 1.5）⇒ 样本变多，但每笔 `r_conv` 的幅度掉到几个百分点，
双边 10bp + 持有期管理费 + 空仓机会成本就能吃掉一半，剩下的信噪比不足以支撑执行纪律。
收紧 `Z_in`（如 3.0）⇒ 幅度够了，但十年不响一次，且触发点全在危机里（回到失败点 2）。
**这个折中不存在中间地带，是本想法先验上最该担心的结构性问题。**
它的危险形态不是「回测不赚钱」，而是**「回测赚钱但十年没出手，于是人会去放宽条件」**——
参数漂移就是这么发生的。
因此规格要求一条**硬性前置门**：

> **近十年（2016 至今）该腿触发 episode 数 < 3 的，无论回测数字多好，一律不得配置资金。**
