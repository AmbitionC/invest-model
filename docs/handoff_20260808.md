# §1 可直接做（不改变投资决策逻辑，风险低）

按建议顺序。**全部属「修量尺」，不碰任何买卖闸、不改仓位。**

### 1.1 `buy_fill_rate` 排除空指令　【实证·已连续三期误报】

**现象**：计划股数=0 的 buy 被判「已执行 100%」并计入分子分母，买点兑现率报 8/9=89%，
真实有效兑现约 1/2。导致「买入守纪律、卖出不守纪律」这个读数是假的（实际两侧都在 50% 上下）。

**根因**：`invest_model/review/execution.py:166` 的一手容忍带在 `planned_shares=0, actual=0` 时命中。

**修法**：新增 `no_op` 状态，`planned_shares=0` 不进分子分母。

**验证**：`python scripts/analysis/review_meta_audit.py` 审计 A 应从「复现」变为「未复现」。

### 1.2 分级表补 `n_h10` 样本量　【确证】

**现象**：复盘第一段两列排序相反——「至今超额」C>A>B，「10 日窗口」A>B>C，
而 `review.py` 的 facts 里 `mean_ret_h10`/`win_rate_h10` **没有对应样本量字段**，
两列矛盾时无从判断谁可信。

**本周新增证据（重要）**：0731→0807 一周内，「至今超额」A 动了 +12.3pp、B 动了 +9.5pp，
而 **10 日列 A/B 完全不变**（+21.3%/+1.8%）。同批标的同一周，一列动 12pp 另一列动 0pp
⟹ 复盘 A1 修订「校准优先看 10 日列」已被直接实证，补 n 是让它可裁定的前提。

### 1.3 JSON 双轨补回　【确证】

**现象**：`results/review/latest.json` 停在 **20260724**。周度复盘迁到 FC 后由
`faas/jobs.py:job_weekly_rebuild_review` 执行，该函数**只 post issue，不产出也不提交 JSON**。
而 `docs/review_schema.md` 写着「固定入口 `results/review/latest.json`，每次复盘覆盖」。

**后果**：任何按 schema 文档从零上下文消费 JSON 的 Agent，会拿到两周前的数据当最新。

**修法**：二选一——FaaS 侧经 GitHub API 提交 `latest.json`，或改 `review_schema.md` 口径声明。

### 1.4 告警熄火留痕　【实证】

**现象**：强风控未执行告警的熄火由**价格**驱动，不由执行行为驱动
（`execution.py:184` `condition_still_valid = last_close <= stop_price * 1.02`）。
一笔拖着不卖的单子，只要等到一次反弹就自动从复盘消失、计数归零。

**修法**：熄火时降级为「曾触发·现已回落」历史行，保留累计计数，不再静默。

### 1.5 复盘补集中度行　【确证】

**现象**：六段无任何集中度指标。**当前卫星化学占持仓 65.6%**（172,726 / 263,406.80），
而 8.4 投顾直播明确「单一方向 15-20%、健康上限不超过 30%」。

**修法**：第三段加「最大单票占比 / 前三大占比」，超阈值出提示。

**现象**：`grep "broad\|leverage\|宽基" scripts/review.py` **零命中**。P27 v2 四腿、
P26 中位线、P28/P30 全部无复盘承接，而 **P30 的后置义务白纸黑字写着「触发记复盘」**。

# §6 两条方法论结论（这两周最有价值的产出）

**① 「机制存在但现实中永不触发」是一类独立缺陷。** 已出现三次：
`direction=exit`（设计了逻辑证伪退出，但投顾不会逐票宣告，于是 research 永不过期）·
