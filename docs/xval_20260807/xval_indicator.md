## 一、恐慌分 fear（`invest_model/signals/fear.py`）

### 1.1 构造拆解

5 个**等权**分量，每个先算原始量再经 `_lin(x, lo, hi)` 线性映射到 [0,100] 并**硬截断**：

| # | 分量 | 原始量 | 映射区间 `_lin` | 数据源 |
|---|---|---|---|---|
| 1 | 动量 `f_mom` | `−(close/MA125 − 1)` | [−0.10, 0.15] | 000300 指数收盘 |
| 2 | 波动率 `f_vol` | 20 日已实现年化波动 | [0.15, 0.35] | 000300 指数收盘 |
| 3 | 宽度 `f_breadth` | `−(站上 MA20 占比)` | [−0.70, −0.15] | 全市场 `stock_daily.close` |
| 4 | 涨跌停 `f_limit` | `跌停/(涨停+跌停)` | [0.20, 0.80] | 全市场 `pct_chg` |
| 5 | 新高新低 `f_hl` | `(120日新低 − 新高)/有效数` | [−0.10, 0.30] | 全市场 `close` |

`score = mean(5)`。分档 <25 极贪 / 25–45 偏热 / 45–55 中性 / 55–75 偏恐 / ≥75 极度恐慌（抄底观察区）。

**复算方法**：分量 1、2 只用指数收盘，我逐日精确复算；分量 3–5 需全市场数据（无 DB），
故用 `resid3 = score×5 − f_mom − f_vol` 反解**三者之和**（score 落盘保留 1 位小数 ⟹ 精度 ±0.25）。
自检：`resid3` 落在 [−0.2, 300.2]，恰好是三个 0–100 分量之和的理论域 ⟹ 复算口径正确。

### 1.4 结论：它实际在测什么

### 🔴 F-A [新发现·波及既有裁决] 贪婪端在「熔涨顶」上对欣快程度**单调反向**，且 20.0 是硬地板

四个方向性分量在任何强势上涨里同时触地（指数 >MA125 +10%、宽度 >70%、跌停占比 <20%、新高多于新低 10%），
此时 `score` **恒等于 `f_vol/5`**，取值域被压进 [0, 20]，而 `f_vol` 随波动**单调递增**。

- 我算的：**2015-06-12 与 2024-10-08 的分量画像逐字相同**（f_mom=0 / f_vol=100 / 横截面三项=0）⟹ **两天都是 20.0**。
  这不是巧合：`vol20` 分别为 36.7% 与 42.9%，都已越过 35% 的封顶线。
- 对照 2025-08-25 一轮平静上涨：`vol20 = 13.7%` 低于 15% 地板 ⟹ `f_vol = 0` ⟹ **score = 0.0**。
- ⟹ **「熔涨顶」的贪婪读数下限是 20.0，永远到不了 0；越欣快、波动越大、读数越"恐慌"。**
  score 恰等于 20.0 的日子全样本 24 天，其中 62% 是完全退化态（f_mom=0、f_vol=100、三项全 0）。
  完全退化态共 93 天（3.3% 交易日），期间指数距 MA125 平均 +24.0%、最低 +10.3%。

**与文档的关系**：F-1 记「贪婪端失灵」并把 2015-06-12=20.0 的十天九天恰等于 20.0 称为「限幅痕迹」。
本节给出该痕迹的**确切来源**（四分量触地 + 波动封顶），并推进一步：**不是分辨力不足，是符号相反**。
⟹ 任何形如「fear 越低越贪婪 ⟹ 越接近顶部」的用法，在熔涨行情里是**反向**的。
E24「高价×极贪」那一支的失败归因应再细化一层：不只是贪婪端没分辨力，而是**它在最该点亮的那天读数偏高**。

### 🔴 F-C [新发现] fear 实测是**小盘宽度温度计**，被当作大盘腿的开闸条件＝宇宙错配

`corr(Δscore, 当日收益)`，我算的，按市值排序**严格单调**：

| 指数 | 中证1000 | 中证500 | 创业板 | 沪深300 | 红利 | 科创50 | 上证50 |
|---|---|---|---|---|---|---|---|
| corr(Δscore, 当日收益) | **−0.729** | −0.714 | −0.634 | −0.600 | −0.575 | −0.525 | **−0.468** |

原因是构造性的：三个横截面分量（宽度/涨跌停/新高新低）在**等权全市场**上计算，
而 A 股 5000+ 只股票里绝大多数是中小盘 ⟹ 它们是「全市场等权宽度」，不是「沪深300 的状态」。

2026-07 那一轮的实际分化（我算的，距 250 日高）：

| 日期 | 上证50 | 沪深300 | 中证500 | 中证1000 | 红利 | 科创50 | 创业板 |
|---|---|---|---|---|---|---|---|
| 20260717 | −10.5% | **−10.5%** | −16.8% | **−20.0%** | −11.6% | −22.3% | −21.6% |
| 20260720 | −7.8% | −9.1% | −17.9% | **−22.2%** | −8.8% | −22.2% | −21.2% |

⟹ **fear=83.5 是对小盘/成长的正确读数，对沪深300 与红利不是。**
但 panic 分支对**四条腿一视同仁**开抢买窗，包括当时只回撤 8.8~10.5%、且都在各自 ×1.30 卖出闸上方的沪深300 与红利。
**这不是"假阳性"，是把 A 指数的体温计接到 B 指数的闸门上。**

### ⚠️ F-D [新发现] 「5 个等权分量」是名义的：日变化 93% 由三个横截面分量驱动

我算的，对 `Δscore` 的方差贡献分解：

| 来源 | corr(·, 当日收益) | 对 Δscore 方差贡献 |
|---|---|---|
| Δ横截面三项/5 | −0.556 | **92.9%** |
| Δf_mom/5 | −0.844 | 4.9% |
| Δf_vol/5 | −0.084 | 2.2% |

（水平值上分布更均衡：横截面 65% / f_mom 18% / f_vol 16%。）
⟹ 描述这个指标时说「5 个等权分量」会误导：**它每天怎么动，几乎完全由全市场个股截面决定**。
这也解释了为什么 `corr(Δfear, 当日收益) = −0.600`：三个横截面分量全部是**当日**收益的函数
（今日 close vs MA20、今日 pct_chg 的涨跌停计数、今日 close vs 120 日高低）。

### ⚠️ F-E [新发现] 档位标定失衡 ⟹「极度贪婪」作 AND 门几乎没有约束力

我算的：**46.2% 的交易日**落在「<25 极度贪婪（高拥挤，收紧）」。这是**众数状态**，不是极值状态。
直接后果——在沪深300 处 expanding 中位线 ×1.30 上方的 1242 天里：

- 同时 `fear < 25` 的占 **52.7%**；同时 `fear < 20` 的占 36.1%。
- ⟹ **「高价 AND 极贪」相对「高价」只筛掉了 47% 的日子**，AND 门几乎不绑定。

这对 E24（P29 顶部合成信号「高价×贪婪×国家队撤退」1/3 未过）是**增量解释**：
除了 F-1 记的「贪婪端在顶部失灵」，还有一层是**这个合取项本身几乎不筛样本**，
所以 E24 实际测的接近于「高价 × 国家队撤退」。（裁决不改——判据跑数前写死。）

### ⚠️ F-F [新发现·待DB确认] 宽度分量把停牌/退市股当作「跌破 MA20」，与两行之下的口径不一致

```python
b20 = float((last >= ma20).mean())          # ← last 为 NaN 时 (NaN >= x) == False，计入分母且判为「跌破」
...
valid = last.notna() & (win.count() >= 60)  # ← 两行之下的新高新低**用了** valid 掩码
nh = int(((last >= win.max()) & valid).sum())
```

`piv` 的列 = **过去 200 自然日内出现过的所有代码**。当日停牌、以及**窗口内已退市**的股票，
在最后一行是 NaN ⟹ 被无声计为「站不上 MA20」⟹ **系统性压低宽度、抬高恐慌分**，
且偏差随窗口内停牌+退市家数增长。同一函数里新高新低用了 `valid` 掩码而宽度没有——**内部口径不自洽**。

灵敏度（我算的）：`f_breadth` 对 `b20` 的斜率 = 100/0.55 ≈ 182 ⟹ b20 每被低估 1pp，score 抬高 0.36 分。
常态停牌+退市约 2–5% ⟹ 常态抬高 0.7~1.8 分；2015-07 全市场半数停牌的极端期会抬高 10 分量级
（那几天本来就是 100，被截断掉了，故不改裁决，但说明该分量在停牌潮里不可解读）。

**待 DB 确认的 SQL**：
```sql
-- 每日：窗口内出现过的代码数 vs 当日实际有收盘价的代码数
SELECT t.trade_date,
       (SELECT COUNT(DISTINCT code) FROM stock_daily s
         WHERE s.trade_date BETWEEN DATE_FORMAT(DATE_SUB(STR_TO_DATE(t.trade_date,'%Y%m%d'),
                                    INTERVAL 200 DAY),'%Y%m%d') AND t.trade_date) AS n_window,
       COUNT(*) AS n_today
FROM stock_daily t WHERE t.close IS NOT NULL
GROUP BY t.trade_date ORDER BY t.trade_date;
-- n_window - n_today 即被误判为「跌破 MA20」的家数；除以 n_window 得 b20 的低估幅度
```

### ⚠️ F-G [新发现·待DB确认] 涨跌停分量用固定 `pct_chg ≥ 9.8`，2019/2020 后口径已结构性改变

```python
lu = (today.pct_chg >= 9.8).sum();  ld = (today.pct_chg <= -9.8).sum()
limit_ratio = ld / (lu + ld) if (lu + ld) else 0.0
```

三个已知的制度偏差：
1. **ST 股（±5%）永远不计入**——真正的极端情绪股被系统性排除；
2. **创业板（2020-08-24 起 ±20%）/ 科创板（2019-07-22 起 ±20%）/ 北交所（±30%）**：
   涨 10~20% 的**普通波动**被计成「涨停」，真涨停（+20%）也只计一次 ⟹ 分子分母同时被稀释；
3. 新股上市首日（无涨跌幅限制）计入 `lu`。

⟹ 2019-07 与 2020-08 之后，这个分量测的已不是「涨跌停情绪」，而是「±9.8% 以上大幅波动股中跌的占比」。
断点回归（我算的，控制当日收益/20日收益/波动/距MA125 后加哑变量）：
以 2020-08-24 为断点 **−1.30 分**、以 2019-07-22 为断点 **−1.66 分**。
⚠️ 该读数与制度变化、市场结构变化混杂，**只能作为「存在断点」的提示，不能作为效应量**。

**待 DB 确认的 SQL**：
```sql
-- 按板块分别统计真涨跌停占比，评估 9.8 阈值的错分率
SELECT trade_date,
  SUM(CASE WHEN code LIKE '30%' AND pct_chg BETWEEN 9.8 AND 19.5 THEN 1 ELSE 0 END) AS chinext_false_lu,
  SUM(CASE WHEN code LIKE '688%' AND pct_chg BETWEEN 9.8 AND 19.5 THEN 1 ELSE 0 END) AS star_false_lu,
  SUM(CASE WHEN pct_chg >= 9.8 THEN 1 ELSE 0 END) AS lu_now
FROM stock_daily WHERE trade_date >= '20200824' GROUP BY trade_date;
```

### ℹ️ F-H [新发现] `limit_ratio` 在「当日无任何涨跌停」时取 0 ＝ 最贪婪

`limit_ratio = ... if (lu+ld) else 0.0` ⟹ `f_limit = _lin(0, 0.20, 0.80) = 0`。
「市场极度平静、一只涨跌停都没有」与「涨停 100 家、跌停 0 家」给出**同一个最贪婪读数**。
A 股常态下 `lu+ld > 0`，故实际影响小；但这是把「无信息」编码成「极值」，是构造缺陷不是保守默认。

### ℹ️ F-I [新发现] 恐慌端同样被削顶：能分「崩没崩」，不能排「崩多深」

我算的，69 个 `≥75` 日：`f_mom = 100` 占 30%、**`f_vol = 100` 占 49%**、三项全顶格占 29%；
而这些日子的**真实**距 MA125 深达 **−29.6%**（闸门 −15% 即封顶）、真实 vol20 高达 **72%**（闸门 35% 即封顶）。
⟹ 一半以上的严重度信息在映射时被丢弃。子样本内 `corr(score, dev) = −0.60`、`corr(score, vol20) = +0.45`
⟹ 仍保有部分排序能力，但 `score = 100` 出现 6 天（2015-08 / 2015-09 / 2016-01 各若干），这些天之间无法比较。

**对 E17/P22/P28/P30 的影响**：这些规则只用「是否 ≥75」这个**二值**判定，不依赖严重度排序 ⟹ **不受本条影响**。
但凡未来想用「恐慌越深仓位越重」（P22 判据①已否），本条是又一条构造上的理由。

### ℹ️ F-J [确认既有·但给出构造证明] 5/5 分量全为价格派生，无任何独立信息源

无成交量、无资金流、无估值、无期权、无信用利差（模块 docstring 已自陈无期权/垃圾债/国债数据）。
其中 **4/5 含当日价**（f_mom 分子、f_vol 末笔收益、f_breadth 的 last、f_hl 的 last），
f_limit 直接是当日 pct_chg 的函数 ⟹ **5/5 含当日信息**。
`corr(Δfear, 当日收益) = −0.600`（文档记同值）**是构造上的恒等结果，不是实证发现**。
⟹ 任何把 fear 与当日/近日收益一起放进回归或条件分组的分析，都存在同期性重复计数。

### ℹ️ F-K [新发现·原假设证否] 未复权价 + 分红集中 5–7 月的季节性偏差**实测很小**

原假设：`stock_daily` 存**未复权**价（`invest_model/data/adjust.py:3` 自陈），

### ⚠️ C-A [新发现] `margin_ratio` 的**分母含价格** ⟹ 三分之一的「两融情绪」是价格的倒数

我算的，`Δln(margin_ratio) = Δln(rzye) − Δln(circ_mv)` 的方差分解：

| 指标 | 分子贡献 | **分母贡献** | corr(Δln 分母, 当日指数收益) | corr(Δln 指标, 当日指数收益) |
|---|---|---|---|---|
| `margin_ratio` | 66% | **34%** | **+0.920** | **−0.488** |
| `turnover` | 101% | −1% | +0.920 | +0.154 |

`circ_mv = 价格 × 股本` ⟹ 它与指数收益的相关是 +0.920（近似恒等）。
`margin_ratio` 有 **34% 的日度方差来自这个价格分母的倒数** ⟹ 它不是一个与价格独立的情绪/杠杆指标。
**这是循环依赖清单里的一条**：把 `margin_ratio` 与价格类信号放进同一个模型或同一张条件表时，
存在同期性重复计数。（`turnover` 分母贡献约 0，因为成交额的波动远大于市值——它是干净的。）
